# 回收类型规则配置中心

需求 ID：`REQ-20261114-001`

交互原型：参数化业务类型与回收类型，通过成交分类规则和物权转移规则生成订单类型版本。

## 本地预览

```bash
cd REQ-20261114-001-回收类型规则配置
python3 -m http.server 4188 --bind 127.0.0.1
```

打开：<http://127.0.0.1:4188/>

## 后台界面基线

本原型采用 **Ant Design Pro v6.0.3 / ProLayout** 的侧边布局信息架构，并通过 `_shared/admin-shell` 的零依赖静态壳层落地：

- 左侧菜单：`240px`，可收起为 `64px`。
- 移动端：小于 `992px` 自动切换为 `260px` 抽屉。
- 顶栏：`56px`，统一承载环境、全局操作和账号信息。
- 菜单分组：工作台、配置、规则与事件、验证与追溯。
- 当前页面：菜单选中态、顶栏页面名、面包屑三者同步。

共享规范见 `../_shared/admin-shell/README.md`，正式 React 工程应直接使用 `ProLayout`，不另建菜单结构。

## 可体验流程

1. 在“业务类型”新增场景，保存并直接进入规则配置。
2. 在“回收类型”新增类型，配置结算、核算主体与旧系统映射。
3. 在“分类规则”组合条件、设置优先级和输出类型。
4. 在“规则试算”运行样本，查看命中链和最终类型。
5. 在“物权转移”模拟实际物权生效后的二次变更。
6. 在“类型追溯”查看规则版本、标签和事件时间线。

## 交互边界

- 所有名称、编码、手机号、订单号和渠道均为脱敏演示数据。
- 数据保存在浏览器 `localStorage`，仅用于原型演示。
- 不连接真实订单、售后、结算或物权系统。
- 重置按钮可恢复初始演示数据。
